# M1. Base e login

**O que é:** Criar o projeto, colocar no ar, banco de dados e login com 3 perfis (loja, creator, Weethub).

**Pronto quando:** As 3 pessoas de exemplo entram e cada uma vê só a sua área.

**Você precisa de:** ninguém, você começa já. Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** todos.

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Criar o projeto Next.js e subir na Vercel
- [ ] Criar o banco (Neon) e ligar
- [ ] Login com e-mail e senha
- [ ] 3 perfis: LOJA, CREATOR, WEETHUB
- [ ] Cada perfil só vê a sua área
- [ ] Avisar o time que a base está pronta

## Regras
- Mexa só nesta pasta (`modulos/m1-base/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m1-base`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
