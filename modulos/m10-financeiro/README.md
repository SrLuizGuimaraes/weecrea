# M10. Financeiro e comissões

**O que é:** Calcular comissão (só pedido pago, desconta cancelamento), carteira de creators, marcar como pago e extrato.

**Pronto quando:** A comissão aparece, some ao cancelar e zera ao marcar como pago.

**Você precisa de:** M4 (Nuvemshop: vendas (pedidos)), M7 (Aprovação e critérios). Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** apresentação.

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Cálculo de comissão por pedido pago
- [ ] Estorno em cancelamento e devolução
- [ ] Carteira de creators
- [ ] Marcar como pago
- [ ] Extrato
- [ ] Financeiro do creator
