# M11. Visão Weethub, testes e apresentação

**O que é:** Telas da Weethub (Painel, Empresas, Creators, Receita), testes do ciclo inteiro, loja piloto e roteiro da apresentação.

**Pronto quando:** O ciclo completo roda sem travar e o roteiro está ensaiado.

**Você precisa de:** M1 (Base e login), M2 (Visual da WEECREA). Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** sócios.

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Painel Weethub
- [ ] Empresas
- [ ] Creators da base
- [ ] Receita
- [ ] Escolher a loja piloto
- [ ] Roteiro de testes do ciclo
- [ ] Roteiro e slides da apresentação

## Regras
- Mexa só nesta pasta (`modulos/m11-weethub/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m11-weethub`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
