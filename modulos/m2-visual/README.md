# M2. Visual da WEECREA

**O que é:** Cores, letras, botões, tabelas, abas, cartões, avisos e menu lateral, iguais à identidade visual, com tema claro e escuro.

**Pronto quando:** Existe uma página de catálogo com todos os componentes para os outros copiarem.

**Você precisa de:** ninguém, você começa já. Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** todos.

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Definir cores e fontes da identidade
- [ ] Botões, campos e etiquetas
- [ ] Tabelas e abas
- [ ] Cartões, avisos e janela (modal)
- [ ] Menu lateral das 3 visões
- [ ] Tema claro e escuro
- [ ] Página de catálogo dos componentes

## Regras
- Mexa só nesta pasta (`modulos/m2-visual/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m2-visual`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
