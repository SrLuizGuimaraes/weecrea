# M2. Visual da WEECREA

**O que é:** Catálogo de componentes, menu das 3 áreas e tema claro e escuro, no estilo do protótipo.

**Pronto quando:** A página de catálogo mostra todos os componentes nos dois temas e funciona em tela de celular.

**Você precisa de:** ninguém, você começa já. Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** todos.

**Sua junção:** Junção 1 (sex 27/11).
