# M3. Nuvemshop: conexão, produtos e cupons

**O que é:** Botão Conectar Nuvemshop, trazer a lista de produtos e criar cupom na loja.

**Pronto quando:** Um produto da loja de teste aparece e um cupom criado pelo sistema existe na Nuvemshop.

**Você precisa de:** M1 (Base e login). Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** M5 (Campanhas e benefícios), M6 (Convite e página de cadastro), M7 (Aprovação e critérios).

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Registrar o app na Nuvemshop
- [ ] Botão Conectar e guardar o acesso
- [ ] Listar produtos
- [ ] Criar cupom para um creator
- [ ] Tela Conexões
- [ ] Tela Produtos e cupons

## Regras
- Mexa só nesta pasta (`modulos/m3-nuvemshop-cupons/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m3-nuvemshop-cupons`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
