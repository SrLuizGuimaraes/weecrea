# M5. Campanhas e benefícios

**O que é:** Criar e editar campanhas (produto, meta, comissão, datas, briefing, tags) e benefícios.

**Pronto quando:** A loja cria uma campanha e o creator aceita.

**Você precisa de:** M1 (Base e login), M2 (Visual da WEECREA), M3 (Nuvemshop: conexão, produtos e cupons). Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** M6 (Convite e página de cadastro), M8 (Vídeos (menções)).

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Lista de campanhas (Ativas, Futuras, Encerradas)
- [ ] Criar e editar campanha
- [ ] Cadastro de benefícios
- [ ] Tags da campanha
- [ ] Tela do creator: aceitar campanha

## Regras
- Mexa só nesta pasta (`modulos/m5-campanhas/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m5-campanhas`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
