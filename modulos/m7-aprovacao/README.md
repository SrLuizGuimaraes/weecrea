# M7. Aprovação e critérios

**O que é:** Critérios mínimos, aprovação automática e fila de análise manual. Ao aprovar, pede o cupom ao M3.

**Pronto quando:** Quem atende aos critérios é aprovado na hora; os outros ficam na fila.

**Você precisa de:** M3 (Nuvemshop: conexão, produtos e cupons), M6 (Convite e página de cadastro). Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** M9 (Painel de vendas), M10 (Financeiro e comissões).

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Tela de critérios (seguidores, engajamento, redes, segmentos)
- [ ] Aprovação automática
- [ ] Fila: aprovar e recusar
- [ ] Lista de creators ativos
- [ ] Pedir o cupom ao aprovar

## Regras
- Mexa só nesta pasta (`modulos/m7-aprovacao/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m7-aprovacao`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
