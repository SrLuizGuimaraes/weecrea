# M8. Vídeos (menções)

**O que é:** Creator envia vídeo por link ou arquivo; a loja filtra, seleciona e baixa um, vários (.zip) ou todos.

**Pronto quando:** Creator envia, loja filtra por campanha e baixa.

**Você precisa de:** M1 (Base e login), M2 (Visual da WEECREA), M5 (Campanhas e benefícios). Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** apresentação.

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Creator: enviar por link
- [ ] Creator: enviar arquivo
- [ ] Loja: galeria com filtros (campanha, tag, rede)
- [ ] Selecionar vários
- [ ] Baixar em .zip

## Regras
- Mexa só nesta pasta (`modulos/m8-videos/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m8-videos`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
