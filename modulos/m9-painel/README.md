# M9. Painel de vendas

**O que é:** Painel da loja (período, creator, ranking, produtos, mapa por estado) e tela Início do creator.

**Pronto quando:** Com pedidos de exemplo, números e gráficos aparecem certos.

**Você precisa de:** M4 (Nuvemshop: vendas (pedidos)), M7 (Aprovação e critérios). Enquanto isso, use os dados de mentira em `dados-exemplo/`.

**Você entrega para:** apresentação.

## Checklist
Marque as caixinhas na **issue do seu módulo** no GitHub (o painel lê de lá).

- [ ] Filtros de período e creator
- [ ] Cartões: vendas, pedidos, creators, comissões
- [ ] Ranking de creators
- [ ] Produtos mais vendidos
- [ ] Mapa por estado
- [ ] Início do creator (cupom, vendas, meta)

## Regras
- Mexa só nesta pasta (`modulos/m9-painel/`). Precisa mudar algo de outro módulo? Peça na issue dele.
- Trabalhe na sua branch `m9-painel`.
- Terminou uma parte? Abra um Pull Request (veja `docs/COMO-INTEGRAR.md`).
